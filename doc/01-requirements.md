# 勤怠管理Webシステム 要件定義書 v1.2

## 1. システム概要

チャットで行っている勤怠報告をWebシステムに置き換える。メンバーがブラウザから打刻し、管理者がリアルタイムで一覧確認・修正できる。

## 2. ユーザーロール

| ロール | できること |
| --- | --- |
| メンバー | 出勤・退勤の打刻 |
| 管理者 | 出勤・退勤の打刻、全メンバーの勤怠一覧確認、打刻データの修正・リセット、アカウント管理 |

## 3. 機能要件（Phase 1）

### 3-1. メンバー画面

- ステータスは **休み（Off） / 勤務中（Working） / 離業中（Away） / 退勤済（Done）** の 4 状態を持つ
- ステータスのデフォルトは **休み（Off）**（未出勤・休み・打刻前を統合した既定状態）
- 勤務形態を選択して出勤打刻（出社 / 在宅勤務 / 直行）→ 休み → 勤務中
- 勤務形態を選択して退勤打刻（通常 / 直帰）→ 勤務中 / 離業中 → 退勤済
- 「直行 → 直帰」のように 1 日に両方発生してもよい
- 離業切替（勤務中 ⇄ 離業中）：昼休み・会議・席離れ等。**離業の開始時刻・終了時刻も記録する**
- 打刻時刻は既定で打刻ボタン押下時のサーバ側自動タイムスタンプ。メンバーが事後に **打刻時刻・勤務形態・離業期間（追加・編集・削除）** を手修正可能
- 自分のステータス表示（休み / 勤務中（勤務形態併記）/ 離業中（勤務形態併記）/ 退勤済）
- 1 日 1 回のみ出勤打刻可（リセット後の再打刻は許容）
- 退勤済からの巻き戻しは不可（誤操作時は管理者リセットで対応）

### 3-2. 管理者画面

- 全メンバー勤怠一覧表示（既定は当日。日付ナビで過去日にも切替可能）
  - 表示項目：名前 / 勤務形態 / 出勤時刻 / 退勤時刻 / ステータス
- ステータス：未出勤 / 勤務中 / 退勤済
- 修正機能：勤務形態・出勤時刻・退勤時刻を編集可能（過去日の編集も可）
- リセット機能：選択日の打刻データを削除して未出勤状態に戻す

## 4. 認証要件

## 6. 業務ルール

### 6-1. 打刻情報の修正

- 打刻時刻の既定：打刻ボタン押下時のサーバ側自動タイムスタンプ
- メンバー自身が **打刻時刻・勤務形態・離業期間** を事後に手修正可能（打ち忘れ・遅延打刻・勤務形態の取り違え・離業時刻のずれ対応）
  - 離業期間は **追加・編集・削除** が可能
- 管理者は修正画面から打刻時刻・勤務形態・離業期間を編集可能（過去日含む）
- リセット（管理者）：選択日の打刻情報（出勤・退勤・離業期間）を初期化し、メンバーが再打刻できる状態に戻す

### 6-2. 勤務形態の組合せ

| 打刻 | 選択肢 |
| --- | --- |
| 出勤打刻 | 出社 / 在宅勤務 / 直行 |
| 退勤打刻 | 通常 / 直帰 |

- 1 日のうちに「直行 → 直帰」のように出勤・退勤の両方が発生してもよい

### 6-3. 当日の定義 / タイムゾーン

- タイムゾーン：JST（Asia/Tokyo）
- 「当日」の区切り：0:00〜23:59
- 深夜跨ぎ勤務は Phase 1 ではケアしない

## 7. ユーザー管理運用

- 管理者がメンバーの **社員 ID・名前・初期パスワード** を発行する
- メンバーは初回ログイン時にパスワードを変更する
- 初期管理者は事前に 1 アカウントだけ存在させる（seed 等で投入）。以降の管理者・メンバーアカウントはこの初期管理者が作成する
- パスワード忘れ時は管理者が再発行する（メンバーによるセルフリセットは不可）
